# 의료데이터 안심활용센터 VDI 코드 반입 및 결과 반출 실무 매뉴얼

## 1. 개요
* 안심활용센터 및 국가암데이터센터의 가상 분석 환경(VDI)은 개인정보보호법에 의거 **외부 인터넷이 원천 차단된 폐쇄망**입니다.
* 따라서 **외부에서 소스코드(Script)를 반입**하고, 분석 후 **통계 요약 결과만 반출**하는 공식 절차를 거쳐야 합니다.

---

## 2. 자료 반입(Ingress) 절차
1. **반입 가능 대상**:
   * 파이썬 스크립트 (`.py`), R 스크립트 (`.R`), SAS 코드 (`.sas`)
   * 조작적 정의 상병코드 매핑 테이블 (`.csv`, `.txt`)
   * *(주의: 외부 임상 데이터나 개인정보가 포함된 파일은 별도 승인 필요)*
2. **신청 방법**:
   * K-CURE 포털 또는 해당 권역 안심활용센터의 **‘자료 반입 신청서’** 작성
   * 반입할 스크립트 압축파일(`.zip`) 첨부 제출
   * 관리자 보안/악성코드 검사(1~2일 소요) 후 VDI 사용자 홈 디렉토리(`G:\userdata#`)로 전송됨

---

## 3. VDI 내 환경 확인 및 실행
1. **사전 패키지 확인**:
   * VDI 신청 시 필요한 라이브러리(PyTorch, Lifelines, Scikit-survival, Scikit-learn, SHAP 등)가 설치되어 있는지 확인하고, 누락된 패키지는 센터 관리자에게 사전 설치 요청.
2. **배치 스크립트 실행**:
   ```bash
   python scripts/run_vdi_pipeline.py --data_path /vdi/data/k_cure_table.parquet --out_dir ./outputs
   ```
3. **학습 로그 남기기**:
   ```bash
   nohup python scripts/run_vdi_pipeline.py > train.log 2>&1 &
   ```

---

## 4. 자료 반출(Export) 절차
1. **반출 허용 기준 (비식별 집계 데이터만 허용)**:
   * **허용**: C-index, AUC 등 평가지표, 회귀계수(Hazard Ratio), 신뢰구간, 혼동행렬, SHAP 요약값, 그래프 이미지, 생존곡선
   * **불가**: 원본 환자 단위 레코드(Raw Data), 셀 빈도수(Cell count)가 5명 미만인 통계표
2. **반출 신청**:
   * 결과 파일 모음 생성 후 VDI 내 반출 신청 시스템(또는 관리자 메일)으로 제출
   * **반출심사위원회**의 비식별 적정성 검토 승인 후 연구자 이메일로 수령
